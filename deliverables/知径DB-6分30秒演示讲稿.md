# 知径 DB 开发演示讲稿

建议配合《知径DB-开发演示稿-最终版》使用，约 6 分 30 秒。方括号内为演示动作提示。

## 0:00–0:25｜项目介绍

各位老师好，我介绍的项目是知径 DB，一套面向《数据库原理》的个性化学习系统。它把学习画像、诊断证据、知识路径和学习资源连接起来，并提供 Web 与 Android 两种使用入口。

## 0:25–0:55｜三类学习者

系统内置基础薄弱、应试巩固和实践导向三种演示画像。它们有不同的学习目标和知识掌握记录，因此首页首推内容不同。这里的账号与分数都是虚构演示数据，不代表真实用户调研结果。

## 0:55–1:30｜学习闭环

诊断证据更新画像中的掌握度，路径算法再参考课程前置关系安排接下来学习什么。新掌握度按旧值百分之七十加本次证据百分之三十计算。当前算法将低于八十的节点作为候选，并补入尚未掌握的前置节点，最多规划八步。

## 1:30–2:00｜差异化路径与知识图谱

课程数据包括九个模块和四十五个知识节点。基础薄弱型首推关系模型，应试型首推第三范式与 BCNF，实践型首推复合索引。每个节点包含目标、难度、关键词、前置关系和来源编号，推荐顺序可以回到具体课程节点核对。

## 2:00–2:35｜六类学习资源

资源库支持讲解文档、知识图解、分层练习、SQL 实操、交互图解和复习卡片。生产环境可以调用 DeepSeek，生成结果先经过 JSON 结构校验；模型调用异常时返回确定性内容。ReviewAgent 在界面与工作流中记录审核状态，目前还没有独立的自动事实核查器，课程事实仍需人工核验。

## 2:35–3:10｜TutorAgent

辅导功能先根据节点标题、课程关键词和英文别名检索证据，再组织回答并展示课程来源。比如输入 candidate key，可以得到候选键解释；如果问题没有匹配到数据库课程知识，系统会明确拒答。

## 3:10–3:45｜SQL 安全实验

SQL 教学库在独立的 sql.js Worker 中运行，每次使用内存中的校园选课数据，执行结束后销毁。查询限制为单条语句、两秒超时和最多两百行；ATTACH、PRAGMA 等语句会被拒绝。演示画面中，三表联查返回三行，危险 ATTACH DATABASE 操作被拦截。这个沙箱不连接业务数据库。

## 3:45–4:15｜技术结构

客户端使用 Expo 和 React Native，共享 Web 与 Android 页面；Hono API 配合 Zod 校验请求；LangGraph 组织资源工作流；课程与代理算法放在共享包中。生产 API 部署在 Railway，Web 使用 Vercel，Android 测试包由 EAS 生成。DeepSeek 密钥只保存在服务端。

## 4:15–5:30｜现场功能演示

[登录 foundation、exam、practice 账号，展示首页推荐差异；打开一条路径及资源详情；向 TutorAgent 提问并展示来源；运行 SQL 查询，再提交 ATTACH DATABASE 观察安全拦截。]

## 5:30–6:10｜验收结果与边界

当前交付包含四十五个课程节点、十二个代理职责、二十一项自动化测试，以及 Web 静态导出和生产配置检查。Android v8 已在真机完成三类账号及主要流程验收，SQL 查询与危险语句拦截也已核验。演示视频已录制，时长约两分三十五秒。生产 API 目前没有配置 PostgreSQL，服务重启后画像和资源缓存不保证保留；真实用户学习效果也尚未评估。

## 6:10–6:30｜结束

知径 DB 已完成从诊断证据到个性化路径、资源、课程问答和 SQL 实操的可运行演示。下一步重点是接入持久化并通过真实学习者评估效果。谢谢各位老师。
