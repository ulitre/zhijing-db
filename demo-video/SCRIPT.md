# 知径 DB 路演 Demo 视频分镜脚本

成片规格：1920x1080 / 30fps / H.264 / 约 3 分 45 秒
受众：投资人、路演评委
主线：不是又一个套壳聊天，而是一条「诊断、规划、生成、评审、练习、掌握度回写」的多智能体学习闭环。
录制数据：后端 deterministic-mock（可复现），SQL 沙箱为真实执行。
旁白：微软中文神经语音 晓晓（女声，+6%，可替换真人）。
字幕：与旁白逐句对齐，烧录进成片。

内部说明（不上屏）：12 个 Agent 是同一 LangGraph 工作流中的角色节点，并非 12 个独立模型；ReviewAgent 是打分与打回的工作流节点，不做独立事实核验。视频文案按此口径表述，避免过度承诺。

## S6 资源合成与评审自愈 01:42-02:28

画面
1. 资源页：目标薄弱节点卡片与六类资源矩阵。
2. 六张卡：讲解文档、知识图解、分层练习、SQL 实操、交互图解、复习卡片，各自标注负责的 Agent。
3. 点击「立即合成」，生成式阅读器逐字呈现内容。
4. 关键镜头：点击「评委演示」，触发初审打回。

旁白

## S7 AI 导师 02:28-03:00

画面
1. 切到导师页：聚焦节点与快捷问题。
2. 选择「循证精讲」模式，输入：候选键和主键有什么区别？
3. 展开 RAG 思考过程：检索、命中、ReviewGuard 三步依次点亮。
4. 答案逐字呈现：一句话定式、深度拆解、SQL 示例、正反例。
5. 镜头扫过引用来源卡片，停在一句核心结论上。
6. 追问一个课程外问题，展示明确拒答，不编造。

旁白
导师不是通用聊天机器人。
它先检索 45 个课程节点与受许可的教材来源，再基于证据作答。
每一句结论都有出处；课程之外的问题，它会明确说不。

## S8 SQL 实验室 03:00-03:30

画面
1. 切到 SQL 实验室：左侧 210 题题库与 8 表结构抽屉，右侧深色编辑器。
2. 从题库选一道多表 JOIN 题，点击「填入标准参考 SQL」，SQL 逐字打入。
3. 点击运行：结果表格弹出，行数滚动；下方 EXPLAIN QUERY PLAN 展开。
4. 掌握度卡片出现增量，点击展开 BKT 明细：先验、后验、新掌握度与公式参数。
5. 徽章庆祝弹层：多表联结专家解锁。

旁白
练习不是选择题。
每个查询都在隔离的 sql.js 沙箱里真实执行，单语句、超时与危险语法都会被拦截。
执行之后，BKT 模型根据表现更新掌握度，并写入学习档案。
错误不会被简单判错，而是记录成可复用的错因。
下一次进入实验室，题目会围绕这些错因重新排序。

## 制作与录制说明

### 录制环境
- 静态站点：`apps/client/dist-video`，本地端口 8082（不动用户已占用的 8081）
- API：`http://localhost:8787`，`deterministic-mock`，内存数据库
- 浏览器：Playwright Chromium，视口 1920x1080，deviceScaleFactor 2
- 每段单独录制，命名 `S01-login.webm` 到 `S11-outro.webm`

### 录制规则
- 隐藏闪烁光标，注入 18px 圆形光标与点击涟漪，节奏放慢到真人操作
- 禁止出现开发工具、滚动条、加载转圈与报错 toast
- 每次开录前调用管理端重置或新开上下文，保证资源列表与掌握度一致
- 关键文字停留不少于 2.5 秒，供观众阅读
- 片头、痛点、片尾为纯设计素材，不录应用

### 配音与字幕
- 微软中文神经语音：`zh-CN-YunxiNeural`（男声，路演）或 `zh-CN-XiaoxiaoNeural`（女声）
- 按场景切分音频，单句不超过 22 字，便于字幕换行
- 字幕样式：思源黑体或微软雅黑，白字 90% 不透明，底部安全区内，关键词用品牌橙高亮

### 合成
- ffmpeg：统一 1920x1080 / 30fps / H.264 / yuv420p / AAC 192k
- 场景间 12 帧交叉淡入淡出，痛点段用硬切强调
- 背景音乐使用可商用曲目或无人声版；没有人声时压低到 -26 LUFS
- 输出：`demo-video/out/zhijing-db-demo.mp4`

### 验收清单
- [ ] 全片无 mock 字样、无 API 地址、无密钥、无调试信息
- [ ] 登录、路径、资源、导师、SQL、画像六个核心场景各至少一个完整动作
- [ ] 旁白与字幕逐句对齐，无错别字，产品名统一为「知径 DB」
- [ ] 画面中不出现「12 个独立模型」「自动事实核验」等过度表述
- [ ] 成片时长 3 分 30 秒到 4 分 30 秒之间，首帧与末帧为黑场
- [ ] 1920x1080 播放无拉伸、无黑边、无掉帧
