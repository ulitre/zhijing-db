# 知径 DB：需求与产品说明

## 项目定位

知径 DB 是面向《数据库原理》课程的多智能体个性化学习系统。它以“校园选课数据库”为贯穿案例，为不同基础、目标和偏好的学生诊断知识断点，规划学习路径，并生成可验证的学习资源。

本项目作为人工智能课程作业交付，不对外提供开放注册。系统内置三类演示学习者：基础薄弱型、应试巩固型和实践导向型。

## 核心闭环

1. 学生选择预设身份进入系统。
2. 系统读取八维画像：前置基础、知识掌握度、学习目标、学习偏好、可用时间、常见错误、资源偏好和进步趋势。
3. 诊断代理根据答题证据更新掌握度：`新掌握度 = 70% × 旧掌握度 + 30% × 新证据`。
4. 路径代理依据 45 个知识节点及前置关系生成动态路径。
5. 资源代理生成讲解文档、知识图解、分层练习、SQL 实操、交互图解和复习卡片。
6. 审核代理检查事实、来源、难度、安全与格式；最多重试一次，失败则返回确定性降级资源。
7. 学习结果回写画像并触发路径重规划。

掌握度小于 60 时补救学习，60–79 时巩固，达到 80 时视为掌握。

## 验收标准

- Web 与 Android 共用一套 Expo/React Native 代码。
- 三类用户获得不同学习路径和资源形式。
- 课程图谱恰好包含 45 个节点，前置引用均有效。
- 12 个代理职责可解释，资源生成过程可追踪。
- 无 DeepSeek/数据库密钥时仍能完整演示。
- SQL 在独立内存数据库 Worker 中执行，禁止危险语句并限制时长与行数。
- 回答带知识来源；课程范围外问题明确拒答。

## 非目标

首版不包含教师后台、正式注册、iOS 发布、向量数据库、模型训练、任意文件上传、实时网络抓取、语音/相机/推送、离线模式和任意 SQL 执行。
