## 页面说明

- 首页：今日建议、学习画像摘要和代理运行进度。
- 路径：依次查看诊断证据、掌握度、推荐节点和推荐资源。
- 资源：六类个性化内容。点开资源卡查看全文、练习答案与解析、知识图或 SQL 实验。
- 导师：限定在数据库课程范围的证据化问答。
- 我的：八维画像、使用帮助和退出登录。

首次启动会显示一次新手引导。使用帮助也可从登录页和“我的”打开。登录态会保存在本机；退出登录会清除该状态。

## 本地运行

```powershell
Copy-Item apps/api/.env.example apps/api/.env
Copy-Item apps/client/.env.example apps/client/.env
pnpm install
pnpm dev:api
pnpm dev:client
```

本地模型密钥只写入 `apps/api/.env`，不要提交该文件。客户端的 `EXPO_PUBLIC_API_URL` 是公开地址，不应放入密钥。当前演示 Web 地址为 <https://client-ten-smoky-12.vercel.app>；最新版 APK 位于 `deliverables/zhijing-db-android-2026-10-05-v5.apk`，使用 HTTPS 生产 API。演示账号与统一密码见本手册开头。
