# 技术架构

## 总体结构

```text
Expo Android / React Native Web
              |
           Hono API
      /         |          \
LangGraph   课程知识图谱    sql.js Worker
   |             |              |
DeepSeek*   PostgreSQL FTS*   隔离校园选课库
   |
ReviewAgent 状态节点 + 确定性降级
```

星号组件为可选云能力。本次生产部署已配置 DeepSeek；生产 Railway 服务尚未配置 `DATABASE_URL`，所以业务数据仍保存在进程内存，服务重启后不会保留。未配置模型密钥的本地模式使用确定性生成器，便于复现实验。

## 代理编排

资源生成固定经过：`Orchestrator → ProfileAgent → DiagnosisAgent → PathAgent → 资源代理 → ReviewAgent 状态节点`。TutorAgent 用于问答，EvaluationAgent 表示学习效果评估职责。资源代理按类型选择 DocumentAgent、DiagramAgent、QuizAgent、SQLLabAgent 或 ReadingAgent。上述多个代理名表示当前工作流中的职责标签，不代表各自运行独立模型。

ReviewAgent 当前将资源标记为审核通过并写入分数，尚未执行独立的事实、来源或难度核查。界面状态不应作为内容正确性的证明，课程事实仍需人工核验。

工作流使用 LangGraph `StateGraph`，开发模式使用 `MemorySaver`，配置 PostgreSQL 后使用 `PostgresSaver`。每个运行以用户和运行 ID 作为检查点线程。

## 数据与检索

- 课程层：9 个模块、45 个知识节点、前置依赖、关键词和来源编号。
- 学习层：八维画像、知识点掌握度、学习证据、动态路径和资源。
- 运行层：代理事件、审核结果与模型用量。
- 检索：首版采用结构化知识图谱、标签与 PostgreSQL 全文检索，不引入向量数据库。

Drizzle 表定义位于 `apps/api/src/db/schema.ts`。没有 `DATABASE_URL` 时写入被安全跳过。

## 安全与可靠性

- DeepSeek 密钥仅存在服务端环境变量，绝不进入 `EXPO_PUBLIC_*`。
- 模型响应异常时最多重试一次；结构化 JSON 解析失败或请求最终失败时使用确定性内容。ReviewAgent 不负责自动事实核查。
- SQL 沙箱每次创建新的内存数据库，执行完即销毁；禁止 ATTACH、PRAGMA、事务控制和扩展加载；仅允许单语句；2 秒超时；最多返回 200 行。
- 公开版本只允许三个预设账号，管理员接口需要独立密钥。
- 教学数据库与业务 PostgreSQL 完全隔离。

## 部署

- API：Railway Docker 服务，地址见部署与交付说明。
- Web：Expo 静态导出后发布到 Vercel。
- Android：EAS `preview` profile 生成内部测试 APK，包名为 `com.zhijing.db`。
- 推荐 Node.js 22 LTS；仓库 `engines` 明确限制为 22.13–22.x。
