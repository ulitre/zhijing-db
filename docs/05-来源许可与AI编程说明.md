# 来源、许可与 AI 编程说明

## 课程知识来源

1. BCcampus, *Database Design – 2nd Edition*, CC BY 4.0：<https://opentextbc.ca/dbdesign01/>
2. PostgreSQL Global Development Group, *PostgreSQL Documentation*, PostgreSQL License：<https://www.postgresql.org/docs/current/>
3. SQLite, *SQLite Documentation*, Public Domain：<https://www.sqlite.org/docs.html>

项目只保存课程节点、目标、关键词、引用元数据和原创中文讲解，不批量复制第三方教材。商业教材只可作为书目信息和课程范围参考。

## AI 辅助开发披露

本项目在需求澄清、架构设计、代码实现、测试用例、文档和界面文案阶段使用 Codex 辅助。开发者负责最终需求确认、运行验证、账号和密钥配置，以及课程提交。

资源运行时可选用 DeepSeek API。模型输入被限制为课程节点事实、学习画像和资源任务；模型输出必须通过结构化校验和 ReviewAgent 审核。未配置 API 或调用失败时，系统使用可重复的确定性资源，因此核心功能不依赖模型在线可用性。

## 隐私声明

演示数据均为虚构信息。首版不采集真实身份、相机、麦克风、精确位置或通讯录，不提供公开注册，也不把数据库和模型密钥打包进客户端。
